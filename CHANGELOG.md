# Історія змін TSukenya

Записи описують прийняті функції. Номер фактично розгорнутого коміту показаний
у «Про застосунок» і `/health`; прийняття PR саме по собі не означає публікацію.
Порядок релізу, копії та відкат — [SERVER-DEPLOYMENT](docs/SERVER-DEPLOYMENT.md).

## 04.10.2026 — main після PR #70 · `5b079bb`

- Місячний бюджет: узгодження незалежних правок виторгу й рядків за UUID;
  зміна складу або порядку рядків потребує явного вибору цілого списку.
- Окремий редактор статей витрат зі збереженням незбереженого плану місяця.
- Підтвердження первісного створення бюджетів і статей за незмінним ключем;
  узгодження локальне, збереження — окрема дія.
- Застосовано additive міграцію `0022`. Чернетки відкритої сторінки ще не
  відновлюються після перезавантаження браузера.

## 04.10.2026 — main після PR #69 · `24b5e0c`

- Задачі, ідеї та планові витрати: точний повтор первісного створення,
  безпечне підтвердження ID, порівняння початкового й поточного запису.
- Повтор не створює дубль після втрати відповіді; змінений або видалений запис
  не повертається мовчки до редагування.
- Застосовано additive міграцію `0021`; для старих записів відсутній початковий
  знімок не вигадується.

## 04.10.2026 — main після PR #66–68 · `94dece2`

- Документи та оплати: збереження чернетки при конфлікті, окреме узгодження,
  захист від повторного створення і повторного проведення.
- Версія шаблону бюджету: обов’язкова звірка кількості магазинів при записі.
- Довідники: квитанції первісного створення й перевірка актуальних прав доступу.
- Застосовано additive міграцію `0020`.

## 04.10.2026 — прийнятий main після PR #65 · `b7ee71d`

- Обмежені серверні списки й звіти, серверна пагінація та CSV;
  окремі доступи до фінансів, складу й довідників.
- Керований worker великих імпортів каталогу, progress/cancel та health.
- React-каталог і Label Studio працюють у порталі; торговельні екрани ще
  використовують `app/`. Повної міграції на React цей запис не заявляє.

Це початок журналу прийнятих змін, а не реконструкція всіх історичних релізів.
Фізичний друк, зовнішні інтеграції та пункт резервування 0.1 залишаються
окремими роботами згідно з планом.
