# TSukenya на VPS

Стан на 30.09.2026. Робоча адреса: <https://tsukernya.pp.ua/>. Сторінка входу відкрита через HTTPS. `www.tsukernya.pp.ua` перенаправляє на основне ім’я зі збереженням шляху й параметрів.

## Склад

- Код і Compose: `/opt/tsukenya`; окремий проєкт Docker Compose `tsukenya`.
- Контейнер `tsukenya-web-1` (Python 3.12, непривілейований UID 10001) доступний лише у мережі `tsukenya_edge`. Порт API не опубліковано на хості.
- SQLite: `/opt/tsukenya/storage/tsukenya.sqlite3`. Папка є постійним bind mount і належить UID 10001.
- Спільний Caddy: `/opt/edge/Caddyfile`, `/opt/edge/compose.yaml`. Gateway підключений до `catering_edge` і `tsukenya_edge`; у Caddy окремий блок для TSukenya. Перед змінами файли скопійовано до `/opt/edge/backups/20260930T051250Z/`.
- Секрет початкового входу є у `/opt/tsukenya/.env`, пароль користувача записано тільки локально в `.private/owner-login.txt` (не у Git). Після зміни пароля через `/account` новий hash живе в SQLite й усі сесії завершуються.
- Перший запуск засіяв 52 товари зі знімка аркуша **Товари** від 29.09.2026. 16 товарів без ціни або закупівлі не мають друкуватися до заповнення ціни.

## Перевірено

- Довірений TLS на основному домені та `www`; `www` повертає 308.
- Приватний вхід, 52 товари після входу, створення і видалення запису, CSRF-відмова на запис без токена.
- Завантаження HTML застосунку і `/runtime.js` після входу.
- Health сервісу, запуск від UID 10001, обмеження 512 MiB/1 CPU/128 процесів.
- Кейтеринг після зміни gateway: `/api/health` відповідає `{"status":"ok"}`; його контейнери healthy.
- Резервну копію SQLite створено через backup API та відновлено в окремий файл; у ній 52 товари.

## Оновлення

1. Зберегти копію поточної БД: `python3 /opt/tsukenya/backup.py`.
2. Перенести потрібні файли з репозиторію у `/opt/tsukenya` без `.env`, `.private` і `storage`. Не видаляти наявний `storage`.
3. `cd /opt/tsukenya && docker compose -f compose.production.yaml config --quiet && docker compose -f compose.production.yaml up -d --build`.
4. Перевірити `docker compose -f compose.production.yaml ps`, `docker logs --tail 100 tsukenya-web-1`, HTTPS і основний сценарій після входу.
5. Для змін Caddy спочатку зробити копії `/opt/edge/compose.yaml` та `/opt/edge/Caddyfile`, перевірити Compose і `caddy validate`, потім відтворити gateway. Не перезаписувати чужі блоки.

## Резервні копії та відкат

`/etc/cron.d/tsukenya-backup` запускає `/opt/tsukenya/backup.py` щодня о 03:15 UTC. Копії з контрольними сумами лежать у `/opt/tsukenya/backups`, локальний строк зберігання — 14 днів. Журнал — `/var/log/tsukenya-backup.log`. **Зовнішнього резервного сховища немає**; втрата VPS може означати втрату і БД, і цих копій.

Для відкату коду зберегти поточну БД, повернути попередні `app/`, `server/`, `compose.production.yaml`, `Dockerfile` і повторити `up -d --build`. Повернення БД з архіву — окрема дія: спочатку зупинити `tsukenya-web-1`, скопіювати чинну БД у безпечне місце, розпакувати вибраний `.sqlite3.gz` у `storage/tsukenya.sqlite3`, виставити UID 10001 і запустити сервіс. Не відновлювати стару БД поверх нової без оцінки втрати змін.

Щоб прибрати маршрут TSukenya, повернути попередні файли gateway з `/opt/edge/backups/20260930T051250Z/` та запустити `docker compose up -d gateway` у `/opt/edge`; це також від’єднає його від `tsukenya_edge`. Дані TSukenya від цього не видаляються. Перед відкатом врахувати подальші зміни інших проєктів у gateway.

## Відкриті питання

- **Google Sheets:** автоматичний двосторонній обмін зі спільною таблицею поки не працює на VPS. Потрібен окремий серверний доступ Google до цієї таблиці. Застосунок прямо показує цей стан; доступний ручний імпорт CSV/XLSX.
- Не перенесено задачі, ідеї, витрати та налаштування приватного Claude Artifact: їхній експорт не надано. Нове сховище для цих розділів починається порожнім.
- PDF візуально перевірено через Poppler; конструктор і друк перевірено браузерним тестом на ізольованій базі. Реального принтера в цьому середовищі немає; потрібен контроль масштабу 100% на вашому пристрої.
- Локальний DNS-кеш на Mac під час запуску ще повертав паркову адресу; публічні `1.1.1.1`, `9.9.9.9` та авторитетний NIC.UA уже повертають `2.28.196.21`.
