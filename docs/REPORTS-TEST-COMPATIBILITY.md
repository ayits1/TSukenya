## Життєвий цикл harness

Legacy `TradeReports.create/mount/cancel` більше не використовується. Для original remount/late401 assertions helper фіксує **справжні options actual Trade.mount('reports', true)**, потім викликає public `ReactReports.mount/leave`; не додає production test exports. Same-host remount має один request handler; leave прибирає DOM, відкладений click на попередній detached action не читає API. Ignored-Abort transport установлюється через addInitScript до того, як typed client зафіксує fetch; скасований late401 реально доходить до obsolete request та не перенаправляє нову сторінку.

Expired session може бути відхилений fresh bootstrap ще до rows GET. Assertion приймає401 тільки цих двох фактичних read boundaries, зберігаючи обов’язкове очищення summary/current debts/source controls/CSV URL **до** login redirect. Permission403 не очікує неіснуючого приватного form/retry: перевіряється public refusal й відсутність приватних regions.
