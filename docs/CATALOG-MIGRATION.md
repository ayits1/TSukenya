# Каталог на React · 01.10.2026

Каталог товарів інтегровано в чинний портал як React-модуль. URL `#operations/products` збережено. Django/PostgreSQL залишаються джерелом даних; складських або грошових проведень каталог не створює.

## Реалізовано

- Пошук за словами назви / штрихкоду та пагінація 10/20/50 на сервері.
- Залежні пошукові комбобокси: група → категорія → пакування; зміна батьківського фільтра скидає дочірні. Фільтри зберігаються при навігації між розділами.
- Компактна таблиця з цінами й акцією; на телефоні — картки без горизонтального виходу.
- Панель створення / редагування: назва, класифікація, пакування, одиниця, штрихкод, мінімальний залишок, закупівля, націнка, ручна ціна, акція та дата перевірки.
- Конфлікт версії: чужа зміна повертає HTTP 409, власний незбережений текст залишається в редакторі. Актуальний запис завантажується явною дією.
- Захист незбережених змін при закритті, переході між розділами та перезавантаженні. Видалення перевіряє версію та використання товару в обліку / рецептурі.
- Чинний імпорт CSV/XLSX, масове оновлення та цінники використовують ті самі документи. Масове оновлення «Показані за фільтром» враховує нові фільтри, а не лише поточну сторінку.

## Контракт та код

- `server/erp/catalog.py`: `/api/v1/session`, `/api/v1/catalog/products`, `/api/v1/catalog/products/{id}`.
- `contracts/catalog.openapi.json`: OpenAPI 3.1; `npm run generate:api` оновлює `frontend/src/shared/api/generated.ts`.
- `tools/api-contracts/`: генератор OpenAPI із сумісним TypeScript 5.9; frontend залишається на TypeScript 6.0. Peer-конфлікт не обходили `--force`.
- `frontend/src/features/catalog/`: мережевий адаптер, список, редактор, стилі, історії та синтетичні fixtures. TanStack Query керує серверним станом; React Aria — взаємодією.
- `frontend/src/catalog-entry.tsx`: монтування / демонтування модуля в чинній оболонці.
- `server/Dockerfile`: збирає Vite в окремому Node-етапі та копіює тільки готові assets у Python runtime.

Суми на новій API-межі — decimal strings; розрахунок продажної ціни виконується серверним Decimal з чинним округленням. Старі JSON-документи зберігають числові поля через явний адаптер сумісності. Редактор не змінює дату ціни при простому перейменуванні; зміна умов ціни або позначка «перевірено сьогодні» оновлює її.

Версія запису — HMAC від поточного вмісту документа та глобальних налаштувань ціни. Збереження й порівняння версії захищені тією самою транзакційною блокадою, що ERP та старий імпорт. Browser adapter передає `If-Match` для чинних товарів; старий API також відхиляє застарілий токен. Касир не отримує закупівлю й націнку та не може редагувати каталог.

## Пов'язані виправлення

Синхронізація з Google Sheets зупиняється до будь-яких записів, якщо зустрічає невідомий ID або не бачить раніше пов'язаного активного товару. Автоматичного очищення чужого рядка чи приховування за неповним аркушем більше немає. Сортування товарів обчислює індекс груп один раз на сортування.

Каталожну оцінку беззбитковості позначено як модель з рівними частками товарів; показано покриття даних. Фактичну структуру продажів та змінні витрати ця модель не замінює.

## Цільові перевірки

```sh
npm run check:frontend
npm run test --workspace frontend -- src/features/catalog/api.test.ts
npm run test:components --workspace frontend -- src/features/catalog/Catalog.stories.tsx
PYTHON_BIN=.venv/bin/python npm run test:catalog:ui
QA_FILTERS_ONLY=1 PYTHON_BIN=.venv/bin/python npm run test:catalog:ui
QA_LAYOUT_ONLY=1 PYTHON_BIN=.venv/bin/python npm run test:catalog:ui
```

Браузерний сценарій використовує **зібраний** Vite-модуль: після зміни frontend зібрати його один раз. Запускає власну тимчасову Django-базу. `QA_BROWSER=webkit` обирає WebKit; звичайний режим — Chromium. Конкурентне редагування перевіряти на ізольованій PostgreSQL через `tests.test_catalog`, а не SQLite чи VPS.

Перевірено: 10 сценаріїв на PostgreSQL, зокрема одночасне редагування; два тести декодування контрактів; чотири історії Storybook; реальний браузерний шлях у WebKit; цільова геометрія 1440/390/320 у Chromium; навігація зі збереженням фільтра та масове оновлення одного відфільтрованого товару; справжній масштаб Chrome 200% у каталозі / редакторі та чинних маршрутах. Повного набору регресій не запускали.

## Наступна межа

Конструктор і торговельні екрани ще використовують `app/`. Оболонка для їх сумісності поки завантажує старий `/api/state` із повним каталогом; новий список має серверну пагінацію, але усунення цього загального завантаження належить наступним етапам міграції. Старий каталог залишено як fallback для середовищ без React-збірки, зокрема попереднього Artifact.

OpenAPI реалізовано для каталогу. DRF, контракт макетів і серверний Google-конектор ще не додані. Для Google-обміну потрібні серверні доступи, журнал запусків, ідемпотентність і координація пристроїв; браузерний прапорець не вирішує цю задачу.
