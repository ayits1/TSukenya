# Поля схеми каталогу 1

Згенеровано з `contracts/catalog-exchange.schema.json`; редагуйте registry, потім `node scripts/generate-catalog-schema.mjs`.

| Поле | Поточний заголовок | Роль у файлі | Формат |
| --- | --- | --- | --- |
| `name` | Назва | Редагування | text |
| `type` | Група | Редагування | text |
| `category` | Категорія | Редагування | text |
| `pack` | Пакування | Редагування | text |
| `size` | Об’єм / вага | Редагування | text |
| `unit` | Од. | Редагування | text |
| `barcode` | Штрихкод | Редагування | text |
| `cost` | Закупівля, грн | Редагування; приватне | decimal (2 знаки) |
| `markup` | Націнка, % | Редагування; приватне | decimal (4 знаки); процентні пункти |
| `manualPrice` | Спосіб розрахунку ціни | Редагування | enum |
| `price` | Ручна ціна продажу, грн | Редагування | decimal (2 знаки) |
| `promotion` | Акція товару | Редагування | boolean |
| `promotionPrice` | Акційна ціна товару, грн | Редагування | decimal (2 знаки) |
| `id` | ID | Селектор оновлення | text |
| `regularPrice` | Звичайна ціна (лише перегляд), грн | Лише перегляд | decimal (2 знаки) |
| `salePrice` | Діюча ціна (лише перегляд), грн | Лише перегляд | decimal (2 знаки) |
| `effectivePromotion` | Чинна акція (лише перегляд) | Лише перегляд | boolean |
| `per100` | Ціна за 100 г (лише перегляд), грн | Лише перегляд | decimal (2 знаки) |
| `priceAt` | Ціна оновлена | Лише перегляд | date |
| `hidden` | Прихований (лише перегляд) | Лише перегляд | boolean |

| Профіль | Полів | Призначення |
| --- | --- | --- |
| `exchange` | 14 | Поточний шаблон імпорту CSV/XLSX |
| `export` | 20 | Django export: редаговані та довідкові поля |
| `artifactBase` | 12 | Сумісна CSV-база Artifact, історичні заголовки |
| `artifactGS` | 15 | Сумісна Google-таблиця Artifact, історичні заголовки |

Касовий export пропускає приватні поля: 18 стовпців. Перша назва поточних файлів містить `[Каталог TSukenya 1]`.
