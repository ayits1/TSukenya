# Серверний імпорт каталогу

## Робочий шлях

На VPS у «Товари й ціни → Імпорт» файл CSV/XLS/XLSX розбирається в браузері, а ціни, помилки та результат визначає Django. POST `/api/v1/catalog/import/preview` не змінює документів. POST `/api/v1/catalog/import/commit` перевіряє знімок і повторно валідовує весь пакет під обліковою блокадою; усі зміни та журнал у спільній транзакції.

- До **1000 товарів / 1 МіБ JSON**, файл до 5 МіБ; великий файл слід розділити. XLSX читається чинним lazy-модулем; CSV працює без нього.
- Порожні клітинки не передають поле, отже зберігають існуюче значення. Явний нуль закупівлі/націнки приймається; ціна ручного продажу має бути додатною. Гроші — десяткові рядки до 2 знаків, націнка — до 4.
- «Ціна» без уточнення потребує вибору закупівлі/звичайного продажу. Стовпці акційної та звичайної цін розділені; діюча ціна визначається сервером.
- Назви зі збіжним регістром/пробілами оновлюють товар; дублікати файлу або неоднозначний каталог — рядкові помилки. ID, якщо є, має відповідати назві. Приховані товари входять до зіставлення і залишаються прихованими.
- Пакет не частковий. Проблемний рядок блокує запис; UI показує номер і причину. Картки попереднього перегляду мають сторінки по 20 рядків, без прихованого «і ще N».
- Зміна товару/налаштувань після preview дає 409 і явне повторне рев’ю. Втрата/некоректна відповідь commit зберігає точний payload і UUID; retry повертає попередній результат без нового запису.
- Після успішного запису failed refresh показує «Імпорт збережено» та retry лише GET. Під час commit навігацію/повторний запис заблоковано. Preview можна скасувати; попередні відповіді не замінюють новий файл. Після непідтвердженого commit новий файл заблоковано до перевірки результату.
- Сеанс/CSRF та ролі owner/manager/warehouse контролює сервер. Касиру/бухгалтеру недоступний інтерфейс імпорту. Google OAuth сервера не налаштовано; UI прямо пропонує експорт аркуша у файл.

## Цільові докази

- `tests/test_catalog_import.py`: 17 API-тестів — preview без запису, атомарність/rollback, колізії ID, повтор/змінений payload, знімок, межі, ціни/акції, ролі/CSRF, історичні довідники, hidden. Спільні catalogue/reference тести також пройшли; SQLite не доводить конкурентність.
- `tests/catalog-import-parser.cjs`: присутність/порожні поля, явний нуль, невалідні числа/boolean, Excel-відсоток, точні line/ID, довільна одиниця, summary-name й 1000 рядків.
- `tests/catalog-import-ui.cjs`: ізольована локальна БД; помилки CSV/рядків і дублів, 25 рядків/сторінки, 1440/390/320; реальний commit з утратою відповіді та точним повтором; конфлікт/перегляд; успішний запис/failed GET; pending route guard.
- `QA_IMPORT_FROM=cancel`: окремий цільовий хвіст для скасування preview, новішого файлу, зміни параметрів і 0.5% без перетворення на 50%.
- `QA_IMPORT_FROM=contract`: некоректний HTTP200 preview блокує commit; некоректна відповідь успішного запису зберігає ключ і не дублює товар.
- `tests.test_catalog_import.CatalogImportConcurrencyTests`: **2 тести PostgreSQL 18 пройшли** на тимчасовому локальному контейнері. Однаковий ключ → два однакові 200 / один запис; різні ключі з одним snapshot → 200+409, без часткового запису програного пакета. Перші спроби зупинились на передумовах QA (окремий Django key і готовність TCP після init restart); після уточнення виконували лише цей етап. Контейнер і дані прибрано.
- TypeScript після генерації OpenAPI та синтаксис JS пройшли. Старі перевірки акцій/друку/синхронізації не змінили результату. Повну регресію не запускали.

## Залишкові межі

Це обмежений пакет, без фонового job/користувацького журналу імпортів. Масова зміна націнки та Artifact-fallback ще використовують старий шлях і потребують окремого перенесення. Уніфікований валідатор не додає нової політики незмінної одиниці використаного товару (B03). Google-синхронізація потребує окремої OAuth-конфігурації та серверної координації (B22). Імпорт не створює довідникові записи з кожного історичного тексту автоматично. Стан непідтвердженого запису живе в поточній вкладці; beforeunload попереджає, але перезавантаження не відновлює сам файл/UUID із диска. Фізичний друк не зачеплено.
