# Масове оновлення цін

03.10.2026. Серверний портал: «Товари й ціни» → «Масове оновлення націнки та округлення». Доступний власнику; сервер перевіряє право незалежно від кнопок.

## Робочий порядок

1. Вибрати націнку й область: усі активні товари, поточні фільтри React-каталогу або категорія. Це весь результат фільтра, не лише поточна сторінка.
2. Явно дозволити перерахунок ручних цін, якщо він потрібний. За замовчуванням вони зберігаються. Для всіх активних товарів можна встановити нову націнку майбутніх товарів.
3. Натиснути «Переглянути зміни». Сервер повертає звичайну й діючу ціну «було → стане», прихованість, пропущені ручні ціни й помилки. По 20 товарів на сторінці; довгі назви переносяться.
4. Перевірити та зберегти весь пакет. Помилка одного товару блокує весь запис. При конкурентній зміні потрібний новий перегляд.

Округлення — окрема глобальна операція. Вона включає приховані товари, зберігає ручні суми й перевіряє акції за запропонованим округленням. Зміна select більше не записує налаштування автоматично.

Зміна націнки майбутніх товарів закріплює стару націнку у необраних товарах без власної націнки, включно з прихованими й пропущеними ручними. Ці метадані видно у перегляді; їхня ціна й дата перевірки не змінюються. Значок «Акція» без окремої акційної суми не дозволяє мовчки змінити базову ціну.

## Сервер і повтори

POST `/api/v1/catalog/pricing/preview` не записує дані. POST `/api/v1/catalog/pricing/commit` приймає той самий план, snapshot каталогу/цінових налаштувань та UUID повтору. Transaction + ledger lock охоплюють товари, налаштування, аудит і результат запиту. Owner та fingerprint закріплені за ключем: той самий пакет повертає попередній результат; інший пакет під тим самим ключем отримує409. Успішна стара відповідь не перезаписує пізнішу зміну товару.

Ліміти: **1000 записів / 1 МіБ JSON**. Нічого не обрізається; явний менший вибір дозволений у великому каталозі. Для глобального округлення чи нового default зі значною кількістю закріплень потрібне окреме майбутнє пакетне завдання. Схему БД не змінено; `pricing_runs/` зберігає результат повтору.

При втраті відповіді форма зберігає незмінний ключ і пакет та пропонує перевірити/повторити саме їх. Новий імпорт блокується до підтвердження результату. Збереження і наступне читання мають окремі результати; повтор оновлення виконує лише GET. Pending запис захищений від зміни маршруту й закриття вкладки. Після повного reload непідтверджений пакет у пам’яті браузера не відновлюється: потрібний майбутній UI журналу серверних запусків.

Інструменти каталогу тепер чекають початкового завантаження ролі, товарів та налаштувань: прямий URL не залишає порожній набір категорій або відсутні owner-кнопки. Ручне введення параметрів не стирається звичайним refresh.

Legacy Claude Artifact зберігає старий послідовний шлях. Цей документ описує інтегрований Django-портал; великі фонові задачі та міграція shell-інструментів у React ще не реалізовані.
