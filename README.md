# Цукерня — мережа магазинів солодощів

Панель власника (міні-CRM) для мережі магазинів солодощів і кав'ярні.

## Що є

- `app/index.html` — дашборд: етапи проєкту, задачі, ідеї, база товарів із цінами й націнками, витрати й точка беззбитковості, цінники (конструктор, друк, PDF, CSV), приховані товари, резервна копія в JSON. Версія — внизу сторінки, історія змін — `CHANGELOG.md`.
  Опублікована версія: Claude Artifact (приватний). Дані зберігаються в базі артефакту, а товари синхронізуються з Google-таблицею «База товарів (з фільтрами)».
- `data/baza-tovariv-template.xlsx` — шаблон бази товарів із фільтрами, закріпленим заголовком і списками вибору (списки — ті самі, що в застосунку).
- `data/baza-tovariv-2026-09-29.csv` — знімок бази товарів на 29.09.2026. ID у ньому порожні: їх присвоює синхронізація.
- `tests/` — тести синхронізації та схеми стовпців.

## Стовпці бази товарів

Заповнюєте ви: Назва · Група · Категорія · Пакування · Об’єм / вага · Од. · Закупівля, грн · Націнка, % · Ціна продажу, грн

Заповнює застосунок під час синхронізації: Ціна за 100 г, грн · Ціна оновлена · Ціна на цінник, грн · ID

Порожня «Ціна продажу» означає, що ціна рахується із закупівлі та націнки.

Джерело правди для стовпців — `GS_COLS` в `app/index.html`. Знімок CSV, шаблон xlsx і цей список мають з ним збігатися, це перевіряє `tests/schema.test.js`.

## Етапи

3. Міні-CRM
4. Інтернет-вітрина з самовивозом

## Розрахунки

- Ціна продажу — ручна ціна або «закупівля × (1 + націнка)», округлена вгору до кроку з налаштувань.
- Точка беззбитковості — витрати на місяць ÷ середня маржа. Продажів у базі ще немає, тож маржа — просте середнє по товарах, у яких є закупівля й ціна; товари-приклади не враховуються. Поруч показано, на скількох товарах порахована цифра, і діапазон за нижньою та верхньою чвертю маржі.
- «Застаріла ціна»: для товару із закупівлею — якщо закупівлю не вносили довше за обраний термін (`costAt`; зміна націнки його не оновлює), для ручної ціни без закупівлі — якщо ціну не змінювали.

Логіка — блок між маркерами `CALC-START/END` в `app/index.html`, тести — `tests/calc.test.js`.

## Синхронізація з Google-таблицею

Дашборд і Google-таблиця «База товарів (з фільтрами)» синхронізуються в обидва боки через конектор Google Sheets:

- зміни в таблиці з'являються в дашборді приблизно за хвилину, зміни в дашборді потрапляють у таблицю за кілька секунд;
- рядок таблиці пов'язаний із товаром через стовпець **ID** (його не можна змінювати);
- якщо одне поле змінили з обох боків, перемагає таблиця;
- видалений у таблиці рядок ховає товар у дашборді (його видно в розділі «Приховані товари»: можна повернути — рядок допишеться в таблицю — або видалити назавжди); видалений у дашборді товар очищує рядок у таблиці;
- застосунок пам'ятає ID видалених товарів (колекція `deletedProducts`) і очищує лише їхні рядки. Рядок із незнайомим ID (вставлений зі старої копії, зі зіпсованим ID) не стирається: він прив'язується до товару з такою самою назвою або стає новим товаром. Якщо видаляєте товар повз застосунок, додайте його ID у `deletedProducts`, інакше рядок повернеться як товар;
- одночасно синхронізує лише одна вкладка чи пристрій (замок `sync/lock` у базі), решта чекає й повторює за кілька секунд. Товари перед синхронізацією читаються з бази заново, а не з локального знімка;
- «Ціна продажу» — ручна ціна; порожня означає «закупівля + націнка», підсумок видно в «Ціна на цінник».

Логіка синхронізації — чиста функція `planSync` між маркерами `SYNC-ENGINE-START/END` в `app/index.html`; запуск із замком і записами — `gsSync` між `SYNC-RUNNER-START/END`.

## Тести

```
npm test
```

Потрібен лише Node.js 20 або новіший, залежностей немає. Тести беруть код просто з `app/index.html` (блоки між маркерами `*-START/END`) і перевіряють синхронізацію, роботу кількох пристроїв одночасно, розрахунки, імпорт накладних і схему стовпців. Якщо щось зламалось, команда завершується з помилкою.

Перевірки в браузері (справжня сторінка з підробленими базою, Google Sheets і завантаженнями: введення тексту під час оновлень, імпорт, фільтри, цінники й PDF, синхронізація):

```
npm i -D playwright && npx playwright install chromium
npm run test:ui
```
